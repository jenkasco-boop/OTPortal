## กฎ OT (จาก `btnAdd_Click`)

นาทีสุทธิ = (จบ − เริ่ม) − พัก แล้วจัดเข้าอัตราเดียวตามเงื่อนไข

| ประเภทวัน | 00:00–08:30 | 08:30–18:00 | 18:00–23:59 |
|---|---|---|---|
| จันทร์–ศุกร์ | 1.5 | ไม่นับ (เวลางาน) | 1.5 |
| เสาร์–อาทิตย์ | 3.0 | 1.0 (Support = 1.5) | 3.0 |
| นักขัตฤกษ์ | 3.0 | 1.0 | 3.0 |

OTxTime = นาทีสุทธิ × อัตรา

คอลัมน์ Excel: No, ชื่อ-นามสกุล, พิเศษ, วัน, วันที่, เข้า, ออก, เวลาเข้า-ออก, ชั่วโมง, นาที, พัก, นาทีรวม, OT 1.0, OT 1.5, OT 3.0, OTxTime, หมายเหตุ, รับทราบ

## ความซ้ำซ้อน / ปัญหา และวิธีที่ระบบใหม่แก้

| โปรแกรมเดิม | ระบบใหม่ |
|---|---|
| พิมพ์ชื่อพนักงานทุกแถว | ตั้งโปรไฟล์ครั้งเดียว จำไว้ในเบราว์เซอร์ |
| ช่วงเวลาข้าม 08:30 / 18:00 / เที่ยงคืน ถูกปฏิเสธ ("ไม่พบ OT") ต้องแยกกรอกหลายแถว | กรอกครั้งเดียว ระบบแยกช่วงและคิดอัตราให้เอง (เช่น เสาร์ 07:00–20:00 = 3 แถว) |
| ข้ามเที่ยงคืนไม่ได้ | เวลาจบน้อยกว่าเวลาเริ่ม = วันถัดไป คิดตามประเภทวันถัดไป |
| ติ๊ก "นักขัตฤกษ์" เองทุกครั้ง | ดึงจากปฏิทินวันหยุดกลาง (ตั้งครั้งเดียว ใช้ทุกคน) |
| กรอกพักทุกแถว | เติมเวลาพักอัตโนมัติเมื่อช่วงเวลาครอบ 12:00–13:00 |
| กรอกเวลาเดิมซ้ำ ๆ | ปุ่มลัดช่วงเวลาที่ใช้บ่อย + จำช่วงล่าสุด |
| ปิดโปรแกรมข้อมูลหาย ต้องกรอกทีเดียวทั้งเดือน | บันทึกลงฐานข้อมูล ทยอยกรอกได้ แก้ไข/ลบได้ |
| ตั้งชื่อไฟล์เอง | ชื่อไฟล์อัตโนมัติ `OT_[YYMM]_[NAME EN]` เช่น `OT_2609_JENWIT.xlsx` |
| ต้องมี Excel ในเครื่อง (COM) | สร้าง `.xlsx` ฝั่ง server (ClosedXML) รองรับ template ของบริษัท |
| ไม่เห็นผลก่อนกด "เพิ่ม" | แสดงผลการคำนวณสด ๆ ระหว่างกรอก |

## จุดที่ระบบใหม่ทำต่างจากเดิม (ตั้งใจ — ตรวจสอบก่อนใช้จริง)

1. **Support วันเสาร์–อาทิตย์ นอกเวลา 08:30–18:00** — โค้ดเดิมได้ 0 (ไม่นับ) แต่ข้อความอธิบายในโปรแกรมเดิมระบุว่า 18:00–23:59 / 00:00–08:30 ได้ 3.0 ระบบใหม่ยึด **3.0** ตามข้อความอธิบาย
2. **เลิกงาน 24:00** — เดิมใส่ได้สูงสุด 23:59 (เสีย 1 นาที) ใหม่ใส่ 00:00 เป็นเวลาจบ = เที่ยงคืนพอดี
3. **การหักพักเมื่อถูกแยกหลายช่วง** — หักจากช่วง 08:30–18:00 ก่อน (พักกลางวัน) ที่เหลือหักช่วงถัดไปตามลำดับเวลา
4. **วันทำงานปกติที่คร่อมเวลางาน** เช่น จันทร์ 17:00–21:00 — เดิมปฏิเสธทั้งรายการ ใหม่นับเฉพาะ 18:00–21:00 และแจ้งเตือนว่าช่วงเวลางานไม่นับ
5. **นักขัตฤกษ์ + Support** — เหมือนเดิม: นักขัตฤกษ์มีผลเหนือ Support (08:30–18:00 = 1.0)
